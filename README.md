# Fagstoff til frontendutvikling

## tl;dr

Repoet inneholder alt av fagstoff til frontendutvikling i Markdown-format slik at det skal være lett å forfatte og strukturere innhold som så kan brukes i Moodle, på websider og lignende. 

## Struktur

Mapper er strukturert på formatet `Emne > Tema > Undertema`. Det er brukt desimalfortegnelse for emne og tema, men ikke for undertema. For eksempel har vi `3. Avansert frontendutvikling > 3.2. Webteknologi` som mappe for alt fagstoff som har med webteknologi å gjøre.

Lag en undermappe for hvert undertema som skal lages fagstoff om. Dersom du har bilder og illustrasjoner kan disse legges i en `assets`-mappe i undermappa, og hvis det er eksterne filer som trenger å legges ved, f.eks JSON-filer eller lignende, kan disse også legges her.

## Bidra?

Har du fått tilgang til repoet og vil bidra, kan dette gjøres gjennom pull requests. Pass på at du forklarer tydelig i PRen hva du har endret eller lagt til, og hvorfor. Større strukturelle endringer i prosjektet skal avklares på forhånd.
